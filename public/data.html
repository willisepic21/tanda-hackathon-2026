Results data

Everything FoldPass visitors produce is kept here, in files you can download and check. Fold results are kept once two devices agree on them. Photo answers are kept with their vote totals.

  1. SolveA device folds a unit from its sequence, seed and attempt count.
  2. CheckThe server confirms the fold is valid and its numbers add up.
  3. RepeatA second device must return exactly the same result.
  4. KeepThe result is appended to validated.jsonl, with device IDs hashed.
  5. PublishDownload it below and re-run it with npm run reproduce.

Check it yourself

The folding search is deterministic, so anyone can re-run archived units and confirm every result matches.

npm run reproduce                                 # 10 random units from the local archive
node scripts/reproduce.js validated.jsonl --all   # every unit in a downloaded file
