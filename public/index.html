A CAPTCHA that puts the work to use

FoldPass checks visitors like any other CAPTCHA, then uses the effort for research. Visitors answer a question from a citizen-science project, or their device runs a short protein-folding search. Every result is checked before it is kept.

How a check works

  1. The visitor checks the box

    FoldPass sends a signed challenge: a photo from a research project, or a protein-folding work unit, plus a small proof-of-work.

  2. Their browser does the work

    The proof-of-work runs in the background while the visitor answers the photo question, or while their device runs the fold search.

  3. The answer is checked

    Each photo check includes one photo with a known answer. Fold results are checked in microseconds and repeated on a second device.

  4. Your server confirms the pass

    Your backend sends the token and your secret to /api/siteverify. Each token works once, for two minutes.

Add it to your site

One script tag and one element. Your server then confirms each token before it accepts the form.

  • Works with any backendVerification is one HTTP request. A Node helper with Express middleware is included.
  • Locked to your domainSite keys can be limited to your hostnames, and every verification reports where the check ran.
  • Invisible mode and donationsFoldPass.execute() runs a check with no widget. FoldPass.volunteer() lets visitors who opt in donate spare CPU.
<!-- In the page -->
<script src="https://foldpass-tanda.fly.dev/sdk/foldpass.js" async defer></script>

<form action="/signup" method="post">
  …
  <div class="foldpass" data-sitekey="demo-site-key"
       data-task="classify"></div>
</form>

// On your server
const r = await fetch('https://foldpass-tanda.fly.dev/api/siteverify', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ token, secret: process.env.FOLDPASS_SECRET }),
}).then((res) => res.json());

if (!r.success) return reject(r.reason);

Where the work goes

Photo answers go to SquirrelMapper, a Zooniverse project studying how city squirrels evolve. A photo's answer is only trusted once several verified visitors agree on it.

Fold results are computed independently on two devices and kept only when they match bit for bit. Each kept result is added to an open dataset that anyone can download and re-run.

Privacy

FoldPass keeps one anonymous device ID in the browser's local storage, separately for each site that uses it. It sets no cookies and does no fingerprinting. Published data replaces device IDs with a one-way hash. Research photos load directly from iNaturalist and Zooniverse.
